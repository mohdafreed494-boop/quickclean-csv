Data Cleaning Rules Configuration

Configure and review standard data transformation rules used by QuickClean.

Active System Rules:

  • Exact Whole-Row Match: Default safe duplicate filter that deletes a row only if every single column value matches another row identically.
  • Target Column Key Match: Flags duplicates based on unique identifiers like Email, SKU, or Customer ID without deleting non-identical rows in other modes.
  • Trim Whitespace: Strips extraneous leading and trailing spaces without changing legitimate internal text spacing.
  • CSV Formula Injection Shield: Automatically sanitizes cells starting with =, +, -, or @ with a safe quote prefix.
  • Client-Side Immutability: The original uploaded file is permanently preserved in read-only memory; exports are created as fresh copies.

Frequently Asked Questions

Q: Does QuickClean send my confidential sheets to a server?
No. All operations run 100% inside your browser's local memory via SheetJS, PapaParse, and Canvas APIs. No spreadsheets ever leave your device.

Q: What file formats are supported?
QuickClean supports `.csv`, `.xlsx`, and `.xls` files directly.
